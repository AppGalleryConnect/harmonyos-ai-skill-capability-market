# CH2025040702131-GridRow组件columns参数和GridCol组件span参数默认值变更

## 来源与版本

身份：扫描Rule ID CH2025040702131。变更版本：6.0.0(20) Beta1。

[完整官方章节](../../changelogs/6.0.0(20)/beta1-os-api-behavior-changes.md#gridrow组件columns参数和gridcol组件span参数默认值变更)（起始行183）；[官网原文](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/changelogs-for-all-apps-6001#ch2025040702131)。接口起始版本、行为版本与target隔离分别核对，不相互替代。

## 旧新行为

columns/span默认值和部分断点补全规则改变，官方明确target≥6.0.0(20)时生效。只提供md/lg时，旧规则下xs/sm的columns=12、span=1，新规则会从更大断点补全为4。

## 影响条件与工程核查

沿GridRow/GridCol完整参数、共享断点配置和封装核对每个实际启用断点及真实窗口宽度；不能因为写过columns/span就认定完整，也不能把断点名称当作当前窗口一定命中。

## 受影响与不受影响示例

只提供部分断点、业务需要原布局的示例：

```ts
GridRow({ columns: { md: 4, lg: 8 } }) {
  GridCol({ span: { md: 4, lg: 8 } }) {
    Text('内容')
  }
}
```

原本已完整配置，或已证实当前启用断点及窗口不依赖改变的补全结果时可无需修改；只见一个设备宽度，不能排除其他已支持窗口。

## 最小方案与边界

需要保留原各断点结果时，显式补齐：

```ts
GridRow({ columns: { xs: 12, sm: 12, md: 4, lg: 8, xl: 8, xxl: 8 } }) {
  GridCol({ span: { xs: 1, sm: 1, md: 4, lg: 8, xl: 8, xxl: 8 } }) {
    Text('内容')
  }
}
```

保持原组件和内容，仅调整本条参数。业务接受新布局时说明依据后无需修改；不能把官方“无需适配”理解为不用核对实际布局，也不借机重构整页或迁移状态管理。

## 验证与证据缺口

覆盖实际受影响窗口宽度、跨断点切换和交互，观察列数、占列、溢出及隐藏区域。共享断点/窗口范围不明时保留缺口，构建成功不证明布局一致。
