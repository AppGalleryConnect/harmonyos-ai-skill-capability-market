# 238-image接口Heif格式类型变更

## 来源与版本

身份：扫描Rule ID 238。变更版本：5.0.2(14) Beta1。

[完整官方章节](../../changelogs/5.0.2(14)/os-api-behavior-changes.md#image接口heif格式类型变更)（起始行1438）；[官网原文](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/changelogs-for-all-apps-b123sp16#imagecomponentoh_packingoptions结构体heif格式编码参数变更)。接口起始版本、行为版本与target隔离分别核对，不相互替代。

## 旧新行为

target≥5.0.2(14)时，相关HEIF格式类型参数/返回值使用image/heic；六类接口并非全部相同，部分结构体已兼容两种值，不能全局替换字符串。

## 影响条件与工程核查

定位实际接口、重载及参数或返回值消费链，区分编码/解码、查询结果和格式识别，核对准确SDK及官方兼容说明。不能仅凭代码出现image/heif认定必须修改。

## 受影响与不受影响示例

| 接口/用途 | 官方变化与处理 |
| --- | --- |
| OH_PackingOptions_SetMimeType | 按准确声明将相关 HEIF 格式参数改为 image/heic |
| OH_PackingOptions_GetMimeType | 相关返回值改为 image/heic，检查消费方判断 |
| ImageSource.supportedFormats | 查询解码支持列表的返回格式变化，检查业务解析 |
| ImagePacker.supportedFormats | 查询编码支持列表的返回格式变化，检查业务解析 |
| image.PackingOption | 官方兼容 image/heif 和 image/heic，不因旧实参出现就强制替换 |
| OH_PackingOptions 结构体 | 官方兼容两种值，与上述 C 函数的参数/返回不能混为一谈 |

已有兼容结构体参数可无需修改；动态返回消费仅支持旧值时需核对新行为。其他协议、日志或扩展名不是本条自动替换对象。

## 最小方案与边界

消费不同系统的查询结果时可在业务识别处兼容两种字符串：

```ts
function isHeifMimeType(mimeType: string): boolean {
  return mimeType === 'image/heif' || mimeType === 'image/heic';
}
```

设置值前核对真实重载与设备行为，不全局改写日志、扩展名、协议或所有编码参数。原生C函数与同名结构体的兼容性不可互代。

## 验证与证据缺口

编码、解码及查询结果消费分别验证，读取实际MIME/文件并回读内容，不能以输出文件名判断格式。缺真实重载、返回值来源或设备证据时保留缺口。
