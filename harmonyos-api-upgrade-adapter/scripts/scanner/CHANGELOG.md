# 变更日志

## 8.2.0 - 2026-11-12

- 支持按 CLI 结构识别 C/C++ 模块超时和命令行上限，登记 26.0.1.412 实测组合，并检查 IDE 引擎的 Java 入口和依赖。

## 8.1.0 - 2026-11-10

- C/C++ 增强扫描按三档启用：已验证构建（表内，当前 26.0.0.821）、未收录但 CLI 源码与全部补丁锚点逐项匹配的构建（标注 ANCHOR_MATCHED）、其余构建使用 DevEco 原生扫描；完整性校验使用检测时取得的本地文件指纹。
