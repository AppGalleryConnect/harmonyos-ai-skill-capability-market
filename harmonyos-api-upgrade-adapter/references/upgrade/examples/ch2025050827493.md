# CH2025050827493-NavDestination的Dialog模式默认支持系统动画

## 来源与版本

身份：扫描Rule ID `CH2025050827493`。

完整名称及ID已核对。依据[官方完整章节](../../changelogs/5.0.1(13)/release-ux-style-and-effect-changes.md#navdestination的dialog模式默认支持系统动画)（139–221行）。变更发布于5.0.1(13) Release，仅应用`targetSdkVersion ≥ 5.0.1(13)`生效；章节起始API Level 9是NavDestination组件起始版本。

本地API 26 SDK：`openharmony/ets/component/nav_destination.d.ts:227,753`确认`NavDestinationMode.DIALOG`和mode接口；`navigation.d.ts:638`的`pushPath(info: NavPathInfo, animated?: boolean): void`、947行`pop(animated?: boolean)`及986行`pop(result: Object, animated?: boolean)`。animated的false关闭转场，带结果的pop需保留结果参数和第二个布尔参数。

## 旧新行为

旧行为DIALOG模式没有系统默认转场；新行为默认携带系统转场。不是所有导航都必须关闭动画：产品接受新转场可保留，只有要维持旧无动画、或与既有自定义效果冲突时才需局部调整。低target保持本条旧规格。

动画差异除了视觉还可能影响对时序的假设；要核查焦点、连续点击和自定义转场，但不能从本条推断生命周期回调固定延后多少毫秒。

## 影响条件与工程核查

核对实际target与构建product，定位`.mode(NavDestinationMode.DIALOG)`以及动态mode、构建器映射和路由表。追踪打开和退出的真实NavPathStack实例、push/pop封装、animated选项以及系统返回/侧滑等入口。若仅扫描到NavDestination，未确认DIALOG，不足以判定受影响。

保存DIALOG节点、路由名到构建器的映射、每个打开/关闭入口及参数、返回结果消费者、自定义动画和产品期望。普通STANDARD页面可排除；Dialog已在所有相关操作显式禁用系统动画且实测符合期望可无需修改。只知道“项目有NavDestination”但路由/模式/操作封装缺失时，记录证据不足。

## 受影响与不受影响示例

以下分别是打开方法和带结果关闭方法内的调用片段，不是在同一方法中连续执行。两者持有现有`stack: NavPathStack`，`editorDialog`确实构建DIALOG页面，`result: Object`是原返回对象：

```ArkTS
// 业务要求保持原无系统转场，且没有依赖系统动画的设计。
stack.pushPath({ name: 'editorDialog' }, false)
stack.pop(result, false)
```

无返回结果的退出使用`stack.pop(false)`；不能把原`stack.pop(result)`直接替换为`stack.pop(false)`，否则结果丢失。若push使用NavigationOptions重载，按已有options维护其其他字段，只调整对应animated字段，不能用布尔重载粗暴替换。

不受影响例：普通STANDARD详情页；或Dialog产品接受新系统动画，经打开/退出回归后保留默认。显式false的既有代码也不需要重复“修复”。

## 最小方案与边界

先选择接受系统转场还是保留原效果。保留旧效果时只修改该Dialog相关的路由操作，关闭相应系统动画，并检查所有退出路径；不要全局关闭Navigation动画以处理一个Dialog。保留路由参数、onPop、返回结果、栈顺序、launchMode等既有语义。

系统返回或手势退出并不一定经过自定义按钮的pop封装，不能修改一处后声称覆盖全部。若当前控制方式不能覆盖某退出路径，继续核对工程已有导航控制能力并记录缺口，不编造NavDestination上的“关闭系统动画”属性。不添加无依据的运行系统分支，不改成非Dialog来逃避动画，因为层级、生命周期和交互语义也会变化。

## 验证与证据缺口

验证打开、按钮返回、系统返回、手势返回、携带结果退出、连续快速打开/关闭、前后台切换；核对自定义效果是否叠加、遮罩和焦点是否正确，原onPop消费者收到的对象是否一致。分别记录本条受影响target及必要旧包对照的视频/截图与路由栈证据。

本案例真实编译、设备动画、系统返回及路由结果测试均未执行。缺少模式、路由封装或返回值契约时只能记录证据不足；高频指导中的“无需适配/不涉及测试”不能替代实际导航体验验证。
