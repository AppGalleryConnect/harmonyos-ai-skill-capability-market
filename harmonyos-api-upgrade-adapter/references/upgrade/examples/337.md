# 337-页面退出场景自定义组件删除前移

## 来源与版本

身份：扫描Rule ID 337。变更版本：5.1.0(18) Release。

[完整官方章节](../../changelogs/5.1.0(18)/os-api-behavior-changes.md#页面退出场景自定义组件删除前移)（起始行637）；[官网原文](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/changelogs-for-all-apps-5101#section337)。接口起始版本、行为版本与target隔离分别核对，不相互替代。

## 旧新行为

target≥5.1.0(18)时，Router/Navigation页面默认退出动画场景下，aboutToDisappear前移到动画过程中；onDisappear仍在退出动画结束后执行。

## 影响条件与工程核查

定位真实路由退出方式、是否默认退出动画、aboutToDisappear中的节点移除/重挂载及全局复用链，确认节点所有权和清理时机，不能把回调命中直接当作所有资源需迁移。

## 受影响与不受影响示例

受影响：全局复用自定义节点在aboutToDisappear被移除或重挂载，与正在进行的退出动画竞争。无需修改：没有相关默认退出动画，或回调仅执行不依赖节点移除时机的工作。退出路径、复用关系不明时先补证。

## 最小方案与边界

仅把确需等待退出完成的节点操作迁移到工程实际可用的退出完成/脱树时机，官方举例为 onDetach；核对具体回调及 SDK 支持范围，保持节点所有权与资源身份。不要把所有订阅取消、定时器和业务清理整体搬到另一生命周期，也不要用固定延时冒充退出完成。

## 验证与证据缺口

记录回调顺序，覆盖正常返回、连续出栈、快速退出和节点复用；核对动画、重复挂载及资源释放，未受影响页面保留原逻辑。 未实测时说明回调顺序、视觉和资源释放均待验证，构建不证明生命周期语义。
