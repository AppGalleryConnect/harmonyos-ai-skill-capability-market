# CH2026031846233-表单类组件触摸热区最小高度变更

## 来源与版本

身份：扫描Rule ID CH2026031846233。变更版本：26.0.0 Beta1。

[完整官方章节](../../changelogs/26.0.0/beta1-ux-style-and-effect-changes.md#表单类组件触摸热区最小高度变更)（起始行36）；[官网原文](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/changelogs-ux-7001#ch2026031846233)。接口起始版本、行为版本与target隔离分别核对，不相互替代。

## 旧新行为

target≥26.0.0时，Button、Button模式Toggle、Select、Chip及ChipGroup默认触摸热区最小高度从28vp变为32vp。变化的是命中范围，不是组件显示高度。

## 影响条件与工程核查

读取完整属性链、共享样式/modifier和状态覆盖，重点核对small尺寸与类按钮，不能只按高度小于32vp判断：

| 真实调用 | 判断 |
| --- | --- |
| Button / Select 使用 ControlSize.SMALL，未自定义高度或热区 | 属于受影响场景，继续判断扩展热区是否影响相邻控件和业务 |
| Toggle 使用 ToggleType.Button，未自定义高度或热区 | 按类按钮场景评估；Switch/Checkbox 模式不属于本条范围 |
| Chip 使用 ChipSize.SMALL，或 ChipGroup.itemStyle.size 为 ChipSize.SMALL，未自定义相关尺寸 | 属于受影响场景；按该组件自身能力提出方案 |
| Button / Select 未设置 SMALL，Chip / ChipGroup 未设置 SMALL，且封装/状态未改为小尺寸 | 本条无需适配，不统一重置热区 |
| 已自定义组件高度或热区 | 官方说明触摸热区随自定义大小生效；确认设置实际生效后无需为本条追加重置，height(28) 也不能因小于32就推断热区会扩大 |
| controlSize、Chip size、高度或热区来自未知动态值/跨文件封装 | 继续读取来源，无法确认时列具体 EVIDENCE_GAP，不猜默认尺寸或扩展像素 |

## 受影响与不受影响示例

受影响的属性链片段（沿用工程现有Chip/ChipGroup导入）：

```ts
Button('small').controlSize(ControlSize.SMALL)
Toggle({ type: ToggleType.Button }) { Text('status') }
Select([{ value: 'select' }]).controlSize(ControlSize.SMALL)
Chip({ label: { text: 'chip' }, size: ChipSize.SMALL })
ChipGroup({
  items: [{ label: { text: '操作块' }, allowClose: false }],
  itemStyle: { size: ChipSize.SMALL }
})
```

无需修改的反例：

```ts
Button('normal')
Select([{ value: 'select' }])
Chip({ label: { text: 'chip' } })
ChipGroup({ items: [{ label: { text: '操作块' }, allowClose: false }] })
Button('自定义高度').height(28)
Button('自定义热区')
  .responseRegion([{ x: 0, y: 0, width: '100%', height: '100%' }])
```

前四项以已确认封装/状态未改为小尺寸为前提，后两项以自定义配置实际生效为前提。height(28)是排除案例，不是建议把原按钮改成28vp；SMALL本身也不等于必须修改。

SMALL按钮仅设置padding而没有生效的自定义高度/热区时，不能以padding或“合理扩大、不影响布局”判未触发。已确认热区变化后检查相邻控件、边缘命中和事件冲突；可选方案默认提出保留旧体验，接受新行为须有具体业务依据和决定，缺命中证据时保留缺口。

## 最小方案与边界

已确认触发且业务需要恢复到组件实际大小的热区时，对支持该能力的组件参考：

```ts
Button('small')
  .controlSize(ControlSize.SMALL)
  .responseRegion(undefined)
```

Chip不支持responseRegion，不能照抄或强转；核对Chip自身size/高度能力。ChipGroup须核对子Chip尺寸，容器热区重置不等于逐个Chip修复。不统一缩小高度，也不未经验证就声称重置后与旧28vp命中范围完全相同。

## 验证与证据缺口

点击组件边缘及扩展区域，核对相邻控件命中、事件次数和可访问性；布局正常不证明热区一致。controlSize、size、高度或热区动态来源不明时补调用链或列EVIDENCE_GAP，不猜默认高度或扩展像素。
