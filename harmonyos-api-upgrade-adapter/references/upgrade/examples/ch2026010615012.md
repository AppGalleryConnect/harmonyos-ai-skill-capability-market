# CH2026010615012-ArkUI接口新增仅支持Stage模型的约束

## 来源与版本

身份：扫描Rule ID CH2026010615012。变更版本：26.0.0 Beta1。

[完整官方章节](../../changelogs/26.0.0/beta1-changes-for-all-apps.md#arkui接口新增仅支持stage模型的约束)（起始行966）；[官网原文](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/changelogs-for-all-apps-7001#ch2026010615012)。接口起始版本、行为版本与target隔离分别核对，不相互替代。

## 旧新行为

ArkUI API10及以上接口补充仅支持Stage模型的约束；FA模型使用这些接口可能产生编译错误，Stage无需为本条修改。接口起始API10不等于本次行为版本，官方未声明target隔离，保持旧target不能规避SDK编译约束。

## 影响条件与工程核查

沿真实工程注册及消费关系定位命中调用所属应用/模块。bundleName所在文件可作入口线索：FA通常在config.json，Stage在AppScope/app.json5；再核对abilities及Ability入口，不以任意同名配置文件断言模型。[FA配置概述](https://developer.huawei.com/consumer/cn/doc/lite-wearable-guides/application-configuration-file-overview-fa)。

## 受影响与不受影响示例

FA config.json相关字段：

```json
{
  "app": { "bundleName": "com.example.fa" },
  "module": {
    "abilities": [{ "type": "page", "srcPath": "js/MainAbility" }]
  }
}
```

Stage module.json5相关字段：

```json
{
  "module": {
    "abilities": [{
      "name": "EntryAbility",
      "srcEntry": "./ets/entryability/EntryAbility.ets"
    }]
  }
}
```

当前应用及相关模块均为Stage时无需适配，可复用模型证据关联全部rowIds，但保留每个调用归属。依赖、夹具、生成目录或另一应用的config.json不证明本应用为FA；同仓库有app.json5也不证明全部独立应用均为Stage。

## 最小方案与边界

确认FA且使用受约束接口时，核对准确SDK声明和真实编译诊断，评估同业务的FA可用替代或Stage迁移范围，纳入方案决定；不只改文件名、补模型标签或加运行时if。HAR核对真实宿主/消费关系，不能由库缺少app.json5推定FA。

## 验证与证据缺口

真实完整构建验证准确SDK下的模型约束；静态证据可支持Stage无需适配，但不能声称构建已通过。归属、配置互相矛盾或HAR宿主不明时列EVIDENCE_GAP及待核查路径，不猜模型。
